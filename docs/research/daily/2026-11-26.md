## 4. D20261126-F01 — Replay continuity temporal negative control and query repair

**Repository facts:** Both runtime transition functions explicitly implement TRUSTED + rollback suspicion -> CONTINUITY_BROKEN. The shared RC-04C fixture requires this transition and denies admission. The mirrored model's TrustedDispatcher lacks this branch; the default self-loop retains trusted state. RestoringDispatcher has a separate rollback-suspected break. The model's nine historical clauses include AuthAdmitted(d) implies earlier TrustedStateEstablished(d) and ContinuityBroken(d) implies earlier RestoringEntered(d). The latter is incompatible with a direct trusted-origin break on a trace that never restarted. September 11 already documents this mismatch. November 26 adds a quantified query-sensitivity canary, not another claim that the mismatch is new.
